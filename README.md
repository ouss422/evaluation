# ملف التقييم والتشخيص

موقع ثابت (HTML/CSS/JS) بلا خادم، تُحفظ البيانات في متصفّح المعلّم (localStorage).

## النشر على GitHub Pages
1. أنشئ مستودعا جديدا على GitHub وارفع كل محتويات هذا المجلد.
2. Settings ← Pages ← Source: **GitHub Actions** (أو Deploy from branch: main / root).
3. يظهر الموقع على `https://<اسمك>.github.io/<المستودع>/`.

## الملفات
- `data.js`: المواد والمعايير والأخطاء وأسبابها وخطط العلاج (قابلة للتعديل من الموقع).
- `exercises.js`: مولّد التمارين العلاجية.
- `app.js`: منطق التطبيق.
