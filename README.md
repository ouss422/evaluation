# ملف التقييم والتشخيص

موقع ثابت (HTML/CSS/JS) بلا خادم ولا مكتبات خارجية؛ تُحفظ البيانات في متصفّح المعلّم (localStorage).

## النشر على GitHub Pages
1. أنشئ مستودعا جديدا على GitHub وارفع كل محتويات هذا المجلد.
2. Settings ← Pages ← Source: **GitHub Actions**.
3. يظهر الموقع على `https://<اسمك>.github.io/<المستودع>/`.

## الملفات
- `data.js`: المواد والمعايير والمؤشرات والأخطاء وأسبابها وخطط العلاج (قابلة للتعديل من الموقع).
- `exercises.js`: مولّد التمارين العلاجية.
- `charts.js`: رسوم SVG (أعمدة ومنحنى) وتنزيل PNG.
- `app.js`: منطق التطبيق (النتائج، تجزئة المعايير، تصنيف الأخطاء، متابعة التلميذ).
